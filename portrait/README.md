本版包含此前印度、北欧、希腊全部跨国合作内容，并在主店、角色展示和地图操作上继续完善。

- 毕方、帝江、羬羊三位代表角色精修水墨立绘和图鉴像素形象，保留独足/红蓝羽翼、无面/六臂四翼、羊角/马尾等既有改编锚点，增加布料、羽片和金属配件层次。其余角色保留既有美术与动作；不是45位人物全部重画。
- 主店更新灶台、蒸煮台、传菜台、收银台、桌席与灯笼素材。工作区随真实设备位置铺设地面标识，设备显出待用/工作状态；蒸汽与火光从实际制作状态读取，不改变设施碰撞或经营路线。

- 双指缩放保留手指下的位置，拖出地图松手、页面切换、窗口变化和应用失焦会清理旧手势，避免返回后无法滑动。
- 系统新增“减弱场景特效”，与原有减弱灯光偏好共用存档。关闭装饰性蒸汽和光晕，跨国场景降低重绘频率；人物、订单、文字与设备状态仍可见。

正式经营、旧存档、电脑与手机自动入口、原文化内容、音乐连续播放与三地订单玩法保留。跨国入口仍为完成白泽开局引导后的“更多→跨国食肆”；精修人物在员工/图鉴及其文化简介中查看。

## 完整包和WorkBuddy

完整包包含全部游戏资源，以压缩分片避免重复下载。先运行根目录prepare-site.py，离线还原为完整site静态目录；根Start-Web.cmd会自动准备并启动本地服务器，需要Python3。部署后的学生仅需浏览器。

在原WorkBuddy项目上传本包，按“给WorkBuddy的更新指令.txt”运行prepare-site.py --site-root <原网站根目录>。它先识别版本、在网站外备份，再更新电脑/手机运行包和资源，保留自定义介绍页；检查后重新部署原应用，沿用原网址和同站存档。不要把压缩包根目录直接发布，不要清除浏览器网站数据。

新立绘和家具由图像生成工具制作，保留生成母图；图集矩形和步行动作锚点为技术取景数据，原PNG不覆盖编辑。三位代表角色的像素展示与场景动作分开读取，未用静态图片替换原有完整工作动画。

验证范围和交付信息见visual-validation-r1.md。自动化采用Chromium触屏/桌面模拟与原生渲染检查；实体手机、Safari及课堂网络仍需实际试玩确认。
