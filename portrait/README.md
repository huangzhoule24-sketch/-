# UI第一阶段 · SH-WEB-UI-R1

本轮落实体验反馈中的UI建议：电脑与手机保留原有经营流程，改善信息层级、功能发现和返回路径。

- 手机顶部保留现金、时间、暂停/调速、当前目标、物品与概览。灵石、声望、负债和工作进度可在概览查看，欠款/员工状态/事件提醒仍会在主界面提示。
- 经营概览显示真实资源、待还本金、培训研发与施工数量，并链接到原账单、物品、系统和人员状态页面。
- 普通管理页面有固定“返回餐厅”和位置提示；子页面的“返回”保留原层级。文化页的返回继续回到读本来源页，顶部关闭及底部返回餐厅可以退出整条阅读路径。装修和强制经营确认仍遵守原完成/撤销/确认规则。
- 更多页面支持按功能名称搜索、显示匹配数量和清空。搜索保留当前阶段开放范围，从详情返回时保留关键词。输入空格不再触发暂停；键盘导致的同宽高度缩小保持搜索与竖屏布局。
- 电脑顶部把资源与操作、管理进度分成两行，正文默认16px；手机继续使用像素边框与清晰字体。
- 手机地图仍可拖动、双指缩放、全景及大厅/后厨/庭院定位，五个底部入口继续随阶段开放。

本轮没有添加菜系、剧情、战斗或新经营规则，不更改原美术音频、经营数值和存档格式。首次打开仍从正式经营进度开始。

电脑和手机共用原站点入口，首页可手动选择设备版本。更新既有WorkBuddy应用时，使用本轮UI补丁，在原项目备份后覆盖、检查，再重新部署当前应用复用域名。不要清除浏览器网站数据。

实际验证范围与下载信息见本轮交付记录。Chromium触控模拟、原生检查不等同于实体手机与Safari验收。
