# 跨国合作食肆 · SH-WEB-INTERNATIONAL-R1

印度晨香廊、北欧港灯食屋和希腊橄榄炉庭已接入正式经营。每地5位当地伙伴、5道菜品，含独立店面与室内场景、角色立绘和像素形象、行走帧、家具、菜单与中英文化阅读。

## 如何进入与游玩

1. 正式开局仍从原山海主店开始；完成白泽的六步引导后，在“更多 → 跨国食肆”接受当地邀请。阶段3的“分店管理”中也有入口。
2. 图鉴增加“跨国伙伴”和“当地菜品”。全部文化阅读可提前查看，不会自动解锁合作能力和配方。
3. 每店筹备费分别350、400、450，按主店游戏记账单位结算，不是现实当地币价。当地协作与场地有每日费用，钱从同一正式存档结算。
4. 在菜单采购并备料；采购转为在制与成品存货，完成交付才收款并结转耗用。菜品随真实当地订单逐步学会，伙伴也随实际接待进展结缘，同时合作两位。
5. 当地团队默认自动核对并交付已备好的适配餐点。循环备料需要主动开启，每批照常扣款，且采购后保留主店现金至少200。也可关闭自动交付，暂停后手动换单、婉拒或出餐。
6. 选择本地接待方案后，实际完成三笔订单会收到对应回信；回信也进入原有“山海来信”。取消与超时按实记载，不会通过点选剧情直接获得营业成绩。

印度侧重发酵、香料与明确的用餐需求；北欧侧重供货消息、天气延误与储备；希腊侧重烤炉、分餐与共享份。设备维护、桌席方案、准备和交接都使用同一游戏时钟；暂停时停止推进。

## 场景与手机操作

店外/店内可切换。地图内部可拖动和缩放，地图外滑动管理列表，使用“全景”恢复镜头。地区、页面与时间操作在上部，固定“返回餐厅”退出当前路径。桌席先预览再付费确认，完成后改变布局与对应经营条件。

界面继续适配电脑与手机竖屏。原主店、音乐连续播放、暂停、图鉴返回和存档规则保留；新模块增加存档字段并兼容旧存档，不自动开启全部原游戏功能。

## 内容来源

神话人物、民俗原型和原创个体在文化资料中分别说明；阿拉克涅的主要传世依据标为奥维德《变形记》第六卷。现代地方菜品不写成神话时代原有食谱。文学小传与出处说明分开，引用资料入口需用户主动展开，不在阅读时自动联网。

新美术使用图像生成工具制作，并以图集区域渲染；保留生成母图。人物职业、合作能力、餐馆故事、配方选择和费用时间是游戏创作。游戏时间是压缩模拟，不是现实烹饪时长或食品处理指南。原典和地区做法的进一步校勘、当地读者审阅仍有后续完善空间。

## 下载与部署

新版完整资源包采用压缩资源储存，所有必要资源均包含在包内，不联网补下载游戏数据。运行包内的prepare-site.py可还原为标准静态网站；Start-Web.cmd会先准备资源，再启动本地浏览器服务器。当地学生只需打开已部署的网站。

更新既有WorkBuddy项目时，在原项目上传资源包，按包内指令先备份，再运行prepare-site.py --site-root <实际网站根目录>；检查后重新部署原应用。不要清除浏览器网站数据，也不要只覆盖HTML或把压缩包根目录直接当作准备好的网站上传。

浏览器检查采用Chromium触屏模拟，不能代替实体Android/iPhone、Safari或课堂网络实测。交付记录会列出实际验证范围。
