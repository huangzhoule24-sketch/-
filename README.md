# 有间晨炊 · 晴日钢琴版

C大调，88 BPM，4/4拍，32小节加自然收尾，约91.27秒。
钢琴主奏及和弦伴奏，低音吉他与轻鼓维持正拍，8处轻三角铁点缀。旋律包含C大调完整七音，避免旧版五声音阶及持续切分伴奏。

这是独立试听版，有自然结尾，未导入游戏，也未自动恢复其他暂停曲目的制作。

原创旋律与编曲由代码辅助制作。钢琴采用Meta Piano的CC0公开立式钢琴样本（https://github.com/facebookincubator/Meta-open-sound），经过移调、包络和混音处理；低音吉他、三角铁及轻鼓为合成音色，不是真人演奏。样本来源固定提交与哈希见sources.json，完整CC0条款见licenses/Meta-Piano-CC0.txt。

输出约−18 LUFS，三种格式实际解码通过，无削波；技术检查不能代替审美试听。游戏文件未改动。
