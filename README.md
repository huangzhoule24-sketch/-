# 跨国食肆场景版 · SH-WEB-BRANCH-R1

本版新增可以替换主经营视窗的印度“晨香廊”、北欧“港灯食屋”、希腊“橄榄炉庭”。三个场景分别使用新绘的廊屋、木屋、庭院底图及当地炉灶、备餐台、出餐台、收银台，桌椅和人物为独立动态物件。

## 怎样解锁与进入

1. 完成白泽原有六步开店引导。
2. 主界面点“场景”，或“更多 → 跨国食肆”。
3. 未开店时查看合作邀请，支付筹备费：印度350、北欧400、希腊450。每日费用仍沿用原来的各店约定。
4. 点“进入此店场景”，或在“场景”中进入已开店铺。切换免费，旧存档已开的店不再收费。“场景 → 返回主店”随时返回。

不是全解锁版本。已有的15位当地伙伴、15道菜、双语文化图鉴、三条合作故事及来信保留。更多伙伴/菜谱继续依照真实结账订单解锁。

## 可以实际经营什么

顾客从店门进入，绕开设施前往座位；前厅人员接单，厨房收到供货后走到设备备餐，前厅从出餐台送至桌边；顾客用餐后步行到收银台付款、离店，再由前厅清台。收入和食材成本在收银完成时各入账一次，不在点击出餐时立即获得收入。旧版的候餐、交接订单会迁移，不重复扣料或收款。

当前店铺可以安排伙伴当班、采购与循环备料、换单/婉拒、自动核对、停接/恢复新客、食街宣传、岗位培训、配方改良、设备维护、布局改造、免费移动桌椅与设备。基础后厨/前厅/收银班组包含在既有合作及日常费用中，命名伙伴参与对应岗位；培训时基础班组补岗。培训提升实际移动速度，配方改良缩短备餐时间，宣传完成后提高一段时间的到店频率。

移动设施：先停接新客、关闭循环备料，等待全部客人离店、清台及工作结束，再选择物件。地图点击预览位置，确认生效，取消保留原位置；挡住座位、设备或进出路线的位置会被拒绝。布局改造仍需费用和真实工时。

主店及各分店共用时间、资金、账本和存档，切换时其他已开店铺继续推进。主店原有财务、探索、集团成长和专属事件仍从全局入口管理，没有把全部主店高级故事逐一复制成三套当地故事。

## 手机与电脑

保留设备识别、手机竖屏界面、触摸拖动和双指缩放。“全景”显示整店，“大厅/后厨/庭院”聚焦工作区；可自由平移缩放。“店外/店内”切换外观与经营图；查看店外时经营照常推进。暂停冻结所有店铺及音乐播放进度，管理操作和切换场景不重启配乐。

## 使用资源包与更新 WorkBuddy

资源包包含全部游戏资源。为了减小下载量，兼容原始分片通过包内已有的gzip文件离线还原，不另从网络下载。

- 本地：解压，在Windows双击根目录Start-Web.cmd（需要Python3）；其他系统执行 `python prepare-site.py --launch`。
- 新网站：运行 `python prepare-site.py`，发布生成的site目录内部。
- 原WorkBuddy应用：上传新包，发送“给WorkBuddy的更新指令.txt”。已有发布目录可执行 `python prepare-site.py --site-root <原网站根目录>`；脚本核对旧版、在网站之外备份、失败回滚并保留自定义首页。随后重新部署**原应用与原域名**，不要清除浏览器网站数据。

学生访问只需要浏览器。可编辑源码另包提供，不能直接当静态网站部署。尚未代用户操作WorkBuddy；大陆现场网络及实体Android/iPhone浏览器需要现场复核。
