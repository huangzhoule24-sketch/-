# 山海食肆物语：离线自由体验版

本包基于当前完整游戏制作，供本地试玩与课堂展示使用。保留原有文化文本、中英切换、水墨立绘、像素场景、人物动画、背景音乐及音效。不会更新现有网页站点。

## 开始游玩

1. 使用 Windows 10/11 64 位，将 ZIP **全部解压**到本地文件夹。
2. 双击 `Start-Game.cmd`。无需联网，无需安装 Godot、Python 或启动服务器。
3. 首次进入已全解锁，选择欢迎页的开始按钮进入餐厅；底部点击“自由控制台”，也可从“更多”进入。初始暂停，可用顶部继续按钮开始营业。
4. 运行不流畅时用 `Start-Low-Power.cmd`（30 帧）；窗口黑屏或显卡兼容问题可试 `Start-OpenGL-Fallback.cmd`。不要拆开 EXE 和同目录 PCK。

支持目标为 Windows 10/11 x64。已做 Godot 原生检查及 Wine 下的 Windows 可执行程序启动检查；没有在真实教室一体机、Windows 7/8、ARM 或所有显卡上测试。低端设备建议先用低占用入口，并在课堂前离线试运行。

## 已开放内容

- 全部经营阶段；拥有全部 30 位员工、25 道菜品（含隐藏配方）。
- 文化图鉴、6 位特殊顾客的介绍、四条文化路线主题及原有文化事件入口。
- 招聘、排班、培训、觉醒、研发、装修、会员外卖、分店、中央厨房、探索、大赛及集团管理等原有功能。
- 默认安排 8 位员工，其余在休息，可自行排班。自由版在岗上限放宽到 30，全部同时在岗可能更占用性能。
- 资金、灵石、食材、招聘券、技能书及碎片已补充；一键补充可再次使用。“全部员工满级满属性”另行点击，方便保留基础属性试玩。

开放入口不代表所有操作自动完成。装修仍需放置实际家具和指派施工员工，探索等仍使用原有流程；可用时间工具推进。事件对话的选择、后续反馈和交互步骤也保留。

## 自由控制台

**倍速**：输入 1–128 的整数，点击应用。1×约为每秒 3 游戏分钟。顶部普通档位仍可使用；高倍速需要更多运算，卡顿时降低倍速。

**真实推演**：+10、+60、+360、+1440 分钟，或输入最多 43200 分钟。逐分钟运行原有经营、订单、培训、装修、探索和日结；分帧执行，可随时停止。它会改变真实经营结果，较长推演需要等待。

**日历跳转**：输入第几日、小时和分钟，可以前后跳转。它只改日历并平移在途任务的计时，**不补算营业、不发放被跳过时段的收入，也不撤回已经发生的账目**。例如，想让培训真正完成，应使用真实推演；想快速改变场景日期，可用日历跳转。

**回溯点**：先记录当前回溯点，再试验；恢复会还原当时的经营状态、人物、计时和随机数状态。回溯点只有一个，重新记录会覆盖上一个。日历向后跳转不能代替回溯。

**资源与体力保护**：默认开启，保底资金、灵石及员工体力、心情、忠诚，避免演示中断。食材消耗仍按原有规则运行，不足时点击补充库存。补充现金记为注资，不冒充营业收入。

**自动随机事件**：默认关闭自动抽取；可开启，也可在底部选择原有事件并手动触发。已有事件、来客对话及剧情反馈仍保留，不是关闭全部故事内容。

**课堂案例预设**：Lin 菜牌交流、毕方炉边宴、当康丰收分配。确认后会重建当前自由体验进度并准备相应条件；之前保存的回溯点保留。请先记录回溯点，再切换案例。按原有事件入口参与对话，不是直接播放全部结局。

## 存档与素材

自由版使用独立应用目录：

`%APPDATA%\Godot\app_userdata\山海食肆物语 · 离线自由体验版\`

- 主存档 `classroom_sandbox.json`。
- 回溯点 `classroom_sandbox_checkpoint.json`。
- 自由版保存/恢复入口始终使用上述独立格式，不覆盖正式版的 `campaign_savegame.json`。正式版也会拒绝把自由版格式当作正常通关存档导入。
- 想保留进度，退出前在控制台点击保存；复制 ZIP 或更新程序不会自动携带本机用户目录中的存档。
- `CustomAssets/` 和 `CustomAudio/` 保留开发者素材替换通道，各目录 README 解释路径和要求。内置完整素材已在 PCK，无需额外下载。
- 启动日志在 `%LOCALAPPDATA%\ShanhaiFreePlay\`。音乐和音效可在游戏设置中分别关闭。

课堂录屏时建议标注“自由体验／演示预设”：这是用于快速展示完整内容的工具，修改后的资金、等级和解锁记录不代表自然通关或真实玩家评价。
