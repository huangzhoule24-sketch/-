# 《山海食肆物语》原生竖屏试用版 · SH-WEB-R9-PORTRAIT

保留正式经营进度、现有美术、配乐、30位员工、25道菜牌及双语文化内容。手机竖屏时按屏幕宽度重新布局，资源数值与主要按钮使用实际CSS像素显示。

- 顶部：现金、灵石、声望、时钟与负债、培训/施工、待办、暂停和倍速；经营概览显示食材、新鲜度及接待数，进账短暂显示于此。
- 底部：随经营阶段开放的四个主要功能与“更多”。
- 餐厅：单指拖动镜头、双指缩放；大厅、后厨、庭院可直接定位。“全景”查看完整餐厅，“专注视图”展开餐厅，再点“恢复界面”回到经营操作。
- 面板：占用手机宽度，长内容直接上下滑动；员工卡、图鉴和操作组可纵向排列。返回、关闭位于固定标题栏。
- 教程：位于底部的独立引导区，操作按钮保持可见，长文字可滑动；管理面板会为引导保留空间。
- 横竖屏切换保持进度及玩家的暂停选择。管理页面按原经营规则暂停时，音乐随之暂停；继续后从原位置接播。

这里的场景调整属于镜头与界面呈现。员工路径、设施位置、座椅遮挡、经济数值、解锁条件和正式存档格式沿用当前版本，旧存档继续适用。该版本不会自动解锁全部功能。

## 打开和部署

在线入口：`https://huangzhoule24-sketch.github.io/-/portrait/`。执行环境对线上域名的访问与课堂手机实际网络分别验证；如原托管平台同步本仓库gh-pages，可在其当前有效域名后访问`/portrait/`，原临时签名有效期由平台控制。

完整网站包可独立上传到现有静态托管平台，入口为index.html，保留game目录。玩家在线打开无需安装Python或Godot。分享页按当前站点生成二维码。

本地电脑：全部解压，安装Python 3后双击Start-Web.cmd。网页需要HTTP/HTTPS，不能直接双击HTML。若在手机试玩，请使用部署后的网站链接。

手机默认采用原生布局；高级兼容入口可在游戏网址增加`wholeview=1`使用此前的整页缩放方式。正常试玩不需要此参数。

## 验证与范围

原生测试覆盖竖屏面板、导航、文化阅读、旋转和触摸镜头。浏览器使用真实触摸输入完成开局教学与付款订单，并检查图鉴阅读、语言、声音、保存/刷新及DPR2/3。主要机型尺寸为360×640、375×667、390×844和430×932，并检查横屏返回。

这些是Chromium触控模拟与本地HTTP检查，尚不能代替实体iPhone、Android、Safari以及课堂网络验收。竖屏试用入口与原有SH-WEB-R8课堂入口分别保留。

## 开发记录

原生竖屏主入口：scripts/ui/phone_layout.gd；通用面板、教程和镜头在对应UI脚本中适配；web/mobile-surface.js负责实际视口和安全区。经营脚本、配置、原美术与音频文件未修改。

此环境未安装完整Godot导出模板，本轮以Godot 4.6.3的Web预设新导出PCK，并复用此前验证过且逐字节相同的4.6.3非线程Web引擎。工具tools/export_portrait_web.py记录引擎来源与校验，网站构建保持分片资源和完整性检查。
