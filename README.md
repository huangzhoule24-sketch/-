# 本包怎么用

建议先看“原32页逐页调整意见”，再看“课堂展示结构调整参考稿.pdf”。PPTX可编辑，每页含演讲者备注，主讲24页、备用4页。

本参考稿另建文件，未覆盖原PPT；保留原稿可用的角色、经营循环与制作线索，但将山海案例、AI写作过程和教师关切放到主线。它是供小组取舍合并的建议稿，不声称代替小组最终决定。

没有把上传PPT原件或其中含昵称/头像的聊天截图放进公开下载包。新稿使用项目现有美术和此前采集的游戏界面；演示预设截图、历史文案和浏览器触控模拟均有标签。没有嵌入未提供的视频，没有虚构市场调研、真人反馈、每人贡献或未实现的法务机制。

PDF和PNG不依赖本机字体。编辑PPT如缺Noto Sans SC，可安装附带字体或在PowerPoint中替换为微软雅黑。软件内实际显示仍以当前版本为准。本次没有改动游戏和网站。
