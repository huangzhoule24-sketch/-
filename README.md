# 山海食肆物语 · 最新可编辑源码

版本：SH-SOURCE-INVENTORY-R1 · 2026年11月4日

本工程保持当前已验证的游戏实现，包含手机版物品栏固定“返回餐厅”、完整角色与菜品、像素场景与水墨立绘、音乐音效、中英切换及电脑/手机布局。默认按正式经营流程解锁。

## 打开工程

1. 全部解压源码主包。
2. 使用Godot 4.6.3导入同目录的project.godot，等待首次资源导入。
3. 在编辑器运行主场景，或命令行执行 `godot --path .`。
4. 要导出Web或Windows，在Godot中安装对应4.6.3导出模板，选择Web或Windows Desktop预设。

源码主包已经包含全部游戏实际使用的图像、字体与音频，可直接运行和编辑。需要重新生成像素图集或重做美术裁剪时，再把美术母图补充包解压到相同目录，使art-source/masters位于工程内。

## 文件位置

- scripts/core：经营与存档逻辑；scripts/ui：界面、地图和手机布局。
- config：角色、菜品、文化、翻译与数值；assets：当前完整运行资源。
- web：网站壳层、手机浏览器适配、设备自动识别入口。
- tests：原生检查；tools：构建、资源处理及验证脚本。
- docs/proposals/feedback-revision-20261104.md：本轮修改意见，只有文档，没有启用新增玩法。

验证示例：`godot --headless --path . --script tests/inventory_return_tests.gd`。
浏览器自动化工具需要另外安装Node.js/Playwright/Chromium；编辑器运行游戏不依赖这些浏览器测试工具。
