# 菜牌核对 · SH-MENU-R5

“核对这道菜的菜牌”现在打开独立说明页，三栏分别说明名字里的故事、这份菜的已列用料，以及上桌前仍需向厨房问清的细节。每道菜都有自己的中英文内容；原完整文化故事继续从页面底部阅读，读完可回到原核对页。

读完点击“确认已读，记入菜牌本”，页面会显示完成状态，菜牌列表为该菜加✓并显示总进度。核对按菜品分别保存；确认阳春面不会替蛋炒饭或其他菜完成。重复确认不会重复增加记录或奖励；这项功能不收费、不消耗食材、不修改菜价，也不替玩家解锁配方或完成订单。

未发现的隐藏配方可先阅读菜名故事，用料栏会说明待发现，确认按钮不可用。配方发现后可再核对。菜名、已列用料、待问事项或实际配方发生变化时，旧记录会显示“说明已更新，请重新核对”；改价与切换界面语言不会擦掉已有用料认识。

Lin的来访在听清饮食需要后提供饺子、酸梅汤的对应核对入口；返回时回到原来访步骤。若已核对这两道菜，Lin会回应菜牌本，确认本次需要时也会保存使用记录。仍需玩家作出换单或退款选择；预约用餐依旧由真实备料、接待、制作与付款完成。通过原“询问需求，核对……”对话确认，也会把本次已核对的两道菜记入菜牌本。

旧存档可继续加载。过去只有一个全局“已核对”标记，无法确定对应菜品，本版不会据此把25道菜一并勾满；已有预约、交易与来信进度保留。

开发入口：config/menu_reviews.json是三栏中英文编辑源；config/cultural_experience.json继续保存菜单基础条目及已知成分。记录在存档culture_experience.menu_reviews，按菜品存内容签名、游戏时间与确认来源；不存界面语言。原menu_reviewed字段仅用于旧版本兼容。美术/音频资源接口、音乐与开关、完整经营、文化读本及Windows课堂启动方式均保留。
