# 像素界面、拖动与座位调整 · 2026-10-28

场景现在可按住鼠标左键直接拖动，松开停止；小幅点按仍可查看员工，拖动不会误打开员工面板。已移除五个场景平移按钮，触屏拖动继续支持。装修落点操作保持独立，避免把放置动作误认成平移。

顾客按到店、等餐、久候、用餐分别使用共26条文本，不使用经营随机数。全店顾客发言间隔至少18个未暂停的真实秒，同一顾客至少60秒；员工自动气泡间隔35秒，最多两个气泡，并与提示、飘字共同限制。气泡位置检查当前员工、顾客、离店人物的身体及姓名区域，同时避让其他气泡，拥挤时隐藏而非盖住人物。暂停不消耗气泡时长。

全画布加入低对比像素底纹，常用界面改为方角、硬边框；早期主字体采用Ark Pixel 12px，本次已依据可读性反馈改为清晰的Noto中文字体，参见clarity-fix.md。像素字体尚未包含的字形由内置字体补齐，保留文化长文、拼音和古文异体字的可读性。Ark Pixel来源及SHA256见assets/fonts/ArkPixel-source.json，OFL许可随包保留；员工原水墨立绘继续使用。

桌面至少72×54个世界单位，椅子增大并按座位方向面向桌面；椅子在人物背景通道绘制，保留人物不被椅子盖住的修复。新局四张桌子分成两排，避免邻桌顾客挤在同一直线；没有强行改动玩家旧档中的自定义布局，旧档可在装修里把桌距拉开。寻路障碍与新的桌面/座点共用RestaurantSpace，仍以实际到站后执行工作。

开发者可继续替换原图，另可手动导入CustomAssets/Map/chair_left.png、chair_right.png、chair_up.png、chair_down.png；缺少方向图时使用程序绘制的像素木椅。原Map/chair.png保留兼容素材，当前四向绘制不再强制使用朝屏幕的单张图。

音乐另行交付《有间晨炊·晴日长笛版》：C大调、88BPM、约91秒，长笛感合成旋律，持续和声取代钢琴，低音拨弦相对降低约9dB，保留三角铁点缀。音乐未导入游戏。
