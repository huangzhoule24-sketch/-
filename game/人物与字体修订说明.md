# 人物站位、字体与柔和长笛 · 2026-10-28

点单、上菜、清台此前将服务员的终点设在顾客椅子上。现在从椅侧约56世界单位处服务；一侧被设施遮挡时尝试另一侧，并检查其他座位及可达路径。新装修不能增加相邻座位的人体空间冲突，旧档仍可载入和逐步拉开桌距。新分配任务采用新站位，旧档已开始的任务保留路线和完成时间，下次任务使用新站位。待命位置也避开座位。

员工、进店顾客与离店顾客使用统一的局部显示避让，移动人物在可通行空地平滑错开，工作中的员工与坐着的顾客不做视觉平移。避让为表现层，不修改经营随机数、存档、工期或设备锁；身体使用38×50世界单位的椭圆近似，并不是完整的人群物理模拟。狭窄过道、旧档过密桌距及交叉瞬间仍可能存在正常的前后遮挡，不能据此声称全部画面人物外接矩形永不相交。原椅子背景通道和稳定Y排序保留。

正文、按钮、数值与文化长文采用内置Noto Sans SC矢量中文字体，补充罕见字与拼音。字体使用2倍采样。场景文字在界面坐标下按至少14字号绘制，不再随箱庭缩成六七像素；姓名与设备标签采用浅底深字卡片，避让其他人物和标签；拥挤时隐藏次要标签，普通顾客状态移至鼠标悬停提示。像素地板、人物、家具、硬边框及外置美术通道保留；Ark字体保留供开发者自行使用。

独立配乐《有间晨炊·柔和长笛版》保留C大调、88BPM、正拍结构及三角铁。长笛旋律降低一个八度，推子相对上一版−5.55dB，2.8kHz柔和低通；低音推子+5dB。声部调整发生在总线响度统一到−18LUFS之前，所以最终峰值差不等于单个推子差。全部声部为代码合成，不是真人录音；不导入游戏。三格式实际解码、削波检查与声部RMS见音乐验证记录。听感以实际试听为准。
