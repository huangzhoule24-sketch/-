# 三地经营场景制作记录

本轮以原主店的入店、寻路、岗位工作、送餐、就餐、收银、离店与清台为参照，先完成可行走的场地与独立设施，再接入实际任务。沿用主店GridNavigation路径计算及CrowdPresentation局部视觉避让；座位/工作点不为凑截图随意挪动。真实路径与账目属于模拟层，渲染层不推进经营或发放收入。

新美术由image_gen生成，三张1120×640逻辑场地的宽幅母图分别突出印度红瓦廊屋与香料架、北欧港口木屋与石砌后厨、希腊白墙蓝窗与橄榄庭院；内部保留大块空地，避免将桌椅人物画死在背景上。另绘4列×3行设备母图，印度/北欧/希腊各含炉灶、备餐、出餐、收银四件。首次设备图出现透明间隙彩色碎点，使用image_gen清理后再接入。另绘2列×3行空桌椅图集，实际餐点仅由订单状态叠加，避免空桌预先摆着食物。空桌图两次透明底尝试未达到要求，后使用image_gen生成品红色键底，运行时仅对该图集尺寸与饱和色键做着色器剔除；不是声称母图已具备透明通道。最终母图原样保留assets/art/BranchFloors；未用Python修改图像像素。

运行时使用AtlasTexture切出设备、新空桌椅和原当地餐点，按同一场地比例绘制。人物沿用原15名当地伙伴的90帧像素行走图和原顾客坐/吃/走多方向动画。基础班组使用原通用人类像素角色，不将其冒称为新神话人物。地方伙伴的工作表现由实际岗位状态、餐盘、工时条、蒸汽和文字状态辅助，未声称重画了15套完整四方向职业动画。

三个场景采用一致的功能分区和导航尺寸，便于相同岗位协作，同时保留各地不同场地材质、建筑、设备外观、菜谱和合作机制。店外继续使用此前已交付的当地立面图。庭院/门口是进出和宣传区，厨房/大厅是备餐与用餐区。
