# 座位与招聘修订制作记录

沿用三地现有5张场景/家具母图及人物资源，本轮没有重画或修改PNG像素。根据桌椅图集中椅面所在的源像素位置建立config/international_seating.json，让候餐显示锚点与实际椅面配准；仍使用原本安全的行走接近点。固定入座阶段不参与移动人物的视觉避让。椅背为背景，共享桌另取原图的桌面区域作为前景，遮挡后排人物腿部；头像与上半身保留在桌沿上方。

招聘页面沿用主店的价格/资源条件、录用与候补排班结构，为当地固定五人候选表提供资金或灵石的定向招聘；没有把原山海角色稀有度、随机保底或山海故事契约冒用到当地角色。移除人物订单数门槛，旧档已合作过的角色迁移为已录用。开业厨师与前厅安排包含在原筹备费用，基础岗位仍可补岗。

截图分为明确标注的原生布局夹具和真实浏览器新局操作。布局夹具为了核对所有椅位主动布满座位，不当作自然营业进度；浏览器则通过正常教学、筹备费、招聘、采购、候餐、实际付款与保存刷新核验。
