# 本轮美术与技术制作记录

延续“水墨立绘＋像素场景与小人”的既有方向。本轮精修三位代表角色，其余角色的完整职业动画继续保留。没有把这一轮描述成45位人物全部重绘。

| 角色 | 必须保留的辨识点 | 精修重点 |
| --- | --- | --- |
| 毕方 | 原拟人化设计中的独足、红蓝羽翼、深色衣装 | 羽片分层、衣褶、皮革与金属扣件 |
| 帝江 | 原拟人化设计中的无面、六臂、四翼、红金色 | 手臂分离、翼羽结构、衣料与金饰层次 |
| 羬羊 | 盘曲羊角、马尾、青绿与米白衣装 | 角的体积、刺绣、衣料前后层与尾部轮廓 |

帝江原典描述为六足四翼；游戏六臂是既有拟人化转译，不把六臂冒充古籍原话。第一张生成图未完整保留六臂，实际审图后重新提出“上下两排都明确三对手臂、四翼、无面”的修正要求，再接入游戏。这是本轮真实发现并纠正的问题。

生成要求的整理版：给出原图、固定角色顺序、正反例与透明留白；先明确形貌锚点，再要求丝绸、羽片、皮革和金属的区别；像素小人保留同一配色和轮廓。此处是方法总结，不是冒充当时逐字聊天记录。

生成母图不覆盖编辑，运行时用AtlasTexture读取对应区域。Python仅分析透明度并输出取景、脚部锚点等JSON数据，没有处理后另存改图。对低透明度边缘使用明确阈值，避免把画布空白算成人物主体；同一角色的六帧使用共同参考高度，避免每帧各自放大造成身体忽大忽小。

主店另制作一张8格物件图集：灶台、蒸煮台、传菜台、收银台、双人桌、四人桌、灯笼和椅。地图里的实际设备位置、占用状态和动线继续来自经营模型。工作区地面与制作状态提供可读反馈，蒸汽和光晕作为可关闭的装饰，不改变出餐时间或收益。

技术上修正跨国人物缩放上限、暂停固定帧跳变、人物脚部落点、双指缩放锚点与框外松手；管理列表在切页、失焦及窗口变化时释放旧手势。设置偏好沿用原存档字段，导入美术仍优先于内置新图。

检查包括三位代表角色、全部原角色头像构图、90帧跨国行走区域、拥挤与动画、真实保存刷新和网页触屏操作。原生截图使用夹具准备的场景，浏览器经营流程使用实际操作；两者分别记录，不能把夹具当作自然通关或实体手机验收。
